# 破产申请与受理

破产程序以「申请—受理」为入口，核心审查对象是债务人是否具备**破产原因**（详见 [[破产原因]]）。

## 一、申请主体与事由（企业破产法第7-9条）

| 申请主体 | 申请事由 |
|---------|---------|
| 债务人 | 不能清偿到期债务，且资产不足以清偿全部债务或明显缺乏清偿能力 |
| 债权人 | 债务人不能清偿到期债务 |
| 清算责任人 | 企业法人已解散但未清算或未清算完毕，资产不足以清偿债务 |

## 二、法院受理审查（企业破产法第10条 + 破产法解释一）

**审查期限**：人民法院自收到申请之日起
- 债权人申请 → **5日内**通知债务人；债务人异议 → 法院自异议期满之日起10日内裁定；
- 债务人申请 → **15日内**裁定是否受理；
- 特殊情况可延长15日。

**破产原因认定**（破产法解释一第1-4条）：
1. 债务人不能清偿到期债务 + 资产不足以清偿全部债务 **或** 明显缺乏清偿能力 → 具备破产原因；
2. 「不能清偿到期债务」三项要件同时具备：债权债务关系依法成立、债务履行期已届满、债务人未完全清偿（解释一第2条）；
3. 「明显缺乏清偿能力」五种情形（解释一第4条）：资金严重不足或财产不能变现、法定代表人下落不明、经强制执行无法清偿、长期亏损扭亏困难、其他丧失清偿能力情形。

## 三、受理的法律效果（企业破产法第16-21条）

- 债务人对个别债权人的清偿**无效**；
- 债务人的债务人/财产持有人应向管理人清偿/交付财产；
- 管理人可解除或继续履行待履行合同；
- 有关债务人的民事诉讼**中止**，统一由受理法院管辖。

## 四、受理异议与救济

- 申请人对不予受理裁定不服 → 10日内向上一级法院上诉（企业破产法第12条）；
- 法院收到申请未及时裁定 → 申请人可向上一级法院申请（破产法解释一第9条）。
