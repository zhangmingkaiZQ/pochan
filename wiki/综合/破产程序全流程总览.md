# 破产程序全流程总览

破产程序是人民法院依照《中华人民共和国企业破产法》，对不能清偿到期债务的企业法人进行债务清理或拯救的特别程序。三种程序形态：**破产清算**（退出）、**破产重整**（拯救）、**破产和解**（协商）。

## 全流程阶段图

```
破产申请 → 审查受理 → 指定管理人 → 债权申报与审查 → 债权人会议
                                                              │
                          ┌───────────────┬───────────────┐
                          ▼               ▼               ▼
                      破产重整         破产和解         破产清算
                      (重整计划)      (和解协议)      (变价分配)
                          │               │               │
                          └───────────────┴───────┬───────┘
                                                  ▼
                                            程序终结 / 注销
```

## 各阶段要点与关联页

| 阶段 | 核心动作 | 关键法条 | 知识页 |
|------|---------|---------|--------|
| 申请 | 债务人/债权人向法院申请 | 企业破产法第7-9条 | [[破产申请与受理]] |
| 受理 | 法院裁定是否受理 | 企业破产法第10-16条 | [[破产申请与受理]] |
| 管理人 | 法院指定管理人接管 | 企业破产法第22-29条 | [[管理人]] |
| 债权申报 | 债权人申报、管理人审查 | 企业破产法第44-58条 | [[债权申报与审查]] |
| 债权人会议 | 债权人行使决策监督权 | 企业破产法第59-69条 | [[债权人会议]] |
| 重整 | 制定并执行重整计划 | 企业破产法第70-94条 | [[破产重整]] |
| 和解 | 达成和解协议 | 企业破产法第95-106条 | [[破产和解]] |
| 清算分配 | 变价、分配、终结 | 企业破产法第107-124条 | [[破产清算与分配]] |
